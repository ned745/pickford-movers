# Pickford Movers — Phase 1

A responsive Flask website starter for Pickford Movers.

## Requirements
- Python 3.10+
- VS Code (recommended)

## Run locally
1. Extract this ZIP.
2. Open the `Pickford_Movers_Phase1` folder in VS Code.
3. Open the terminal in that folder.
4. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

5. Activate it on Windows:

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt:

   ```bat
   venv\Scripts\activate
   ```

6. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

7. Start the website:

   ```bash
   python app.py
   ```

8. Open `http://127.0.0.1:5000` in your browser.

## Included
- Responsive navy, gold and white design
- Home, services, about, gallery, contact and quote pages
- WhatsApp contact link
- Mobile navigation
- AI assistant interface mockup (not connected to an AI service yet)
